Preferred text size ​

By default, the text is scaled to fit the field, which means that its final size depends on how much text the customer types. If you want the text to be printed at a fixed physical size instead, set the Preferred text size (pt) option in the field settings.

The option is available on fields that have the Display as text field option enabled. Leave it at 0 to keep the automatic behaviour.

When a size is set:

  • The text is rendered at that exact size in points, no matter how much text is entered
  • Long text wraps onto a new line at the field width instead of shrinking to fit

TIP

The size is converted using the real size of the side, so make sure the real size is configured correctly, otherwise the printed text will not match the requested size.

WARNING

The preferred size is ignored for vertical and curved texts. They fall back to the normal text rendering.

Single item only ​

Enable this option if the field should hold only one design item.

When it is enabled, adding a text to the field replaces the one already there, and the duplicate button is hidden for that field. Leave it disabled to let customers stack several texts in the same field.
